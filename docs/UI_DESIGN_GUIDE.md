# Tulsi Mart – UI Design Guide

## 1. Tulsi Mart Brand Identity
The UI is styled around a modern, energetic retail identity:
- **Primary Orange**: `#FF6700` (action buttons, active highlights, key metrics)
- **Light Orange**: `#FFD7B5` (borders, badges, subtle accent backgrounds)
- **Background**: `#FFF8F3` (warm tinted store canvas)
- **Surface / Card Background**: `#FFFFFF`
- **Dark Text**: `#222222` (high-readability headings)
- **Secondary Text**: `#64748B` (labels and captions)

---

## 2. Iconography Standards
- **Vector SVG Icons Only**: All icons use the Lucide icon set via `react-native-svg` through the central `AppIcon` component.
- **Strictly No Emojis**: Emojis are banned as functional UI icons across the application.
- **Semantic Color Coding**:
  - Dashboard: `#FF6700` (Orange)
  - Products & Inventory: `#2563EB` (Blue)
  - Customers & Khata: `#16A34A` (Green)
  - Suppliers & Vendors: `#7C3AED` (Purple)
  - Billing & POS: `#FF6700` (Orange)
  - Orders: `#0D9488` (Teal)
  - Expenses & Alerts: `#DC2626` (Red)
  - Settings & System: `#64748B` (Gray)

---

## 3. Typography & Spacing
- Font Scale:
  - Header: 20px, Bold (800)
  - Card Title: 16px, Semi-Bold (700)
  - Body Text: 14px, Regular (400-500)
  - Metadata / Caption: 11-12px, Regular
- Spacing Scale:
  - XS: 4px
  - S: 8px
  - M: 12px
  - L: 16px
  - XL: 24px
